# Conalco Price Monitoring

R-Pipeline zur Erhebung und Auswertung von Conalco-Produktangeboten. GitHub
enthält den Code, den Workflow und synthetische Tests. Der Workflow stellt
den vollständigen privaten Forschungsbestand vor jeder Erhebung wieder her.
Er archiviert Rohdaten und validierte Ergebnisse in der bestehenden privaten
Archivkette. Die öffentliche Datenpublikation ist in diesem Workflow nicht
enthalten.

R 4.6.0 und die Paketversionen aus `renv.lock` sind für die Reproduktion
maßgeblich. Die [Betriebsdokumentation](docs/operations.md) beschreibt
Startvoraussetzungen, Tests, Geheimnisse und Wiederaufnahme.
